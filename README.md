# Ejercicio-biblioteca-conectada-a-BBDD-con-Java
Gestión de biblioteca en Java conectada a MySQL mediante JDBC. Implementa el patrón DAO para realizar operaciones CRUD (Crear, Leer, Actualizar, Borrar) sobre una tabla de libros. Incluye clases para la conexión, el modelo de datos y lógica de negocio, con un menú interactivo y uso de PreparedStatement por seguridad.
